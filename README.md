# Moje knihovna

Mobilně orientovaná Angular PWA pro správu osobní knihovny bez backendu.

## Co umí
- skenovat ISBN/EAN-13 přes kameru
- dohledat metadata přes Google Books s fallbackem na Open Library
- ukládat knihy lokálně do IndexedDB pomocí Dexie
- offline zkontrolovat, jestli už knihu doma máte
- ručně přidat knihu, když sken nebo metadata selžou

## Spuštění
```bash
npm install
npm start
```

## Build
```bash
npm run build
```
